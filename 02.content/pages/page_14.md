# PAGE 14 — WHAT EXACTLY IS IMPAIRED?

**Reader question:** What can go wrong, and how far does the diagnosis need to go?

one cross-reference renumbering. See `../../00.project/changelog.md` for the full

A useful starting diagnosis is to test four potential sources of impairment.

**Operational** — the asset is enrolled and funded correctly, but day-to-day execution
is failing: claims aren't lodged, records are poor, vacancy isn't being actively
managed. **Provider / Contractual** — the provider relationship itself is the problem:
an unfavourable fee structure, unclear vacancy-risk allocation, a provider under
pressure, or a contract that blocks a clean transition. **Capital Structure** —
ownership, debt or security arrangements constrain recovery independently of, or in
addition to, operating performance. **Fundamental Asset** — location, design category,
configuration or realistic participant demand does not support the original SDA
proposition.

These four sources are a diagnostic starting point, not an exhaustive substitute for
Specialist SDA Commercial Vendor Due Diligence. Some engagements require a forensic
level of commercial investigation — testing for hidden commercial conflicts or
dependencies (related-party arrangements, undisclosed dependencies, participant/
provider incentives, cross-entity arrangements) rather than an accusation against any
identified party.

Identifying which source — or combination — applies determines the realistic recovery
pathway. This is the working diagnosis the decision tree on page 22 tests further.
