Specialist Disability Accommodation, or SDA, is an emerging asset class. The New
Build classification began on 1 April 2016, so data on New Build dwellings has
existed for only around a decade; granular data is limited and, in many instances,
not publicly available, and public comparable-sale evidence remains limited. A
common source of value leakage is treating an SDA appointment as a conventional
property realisation — because an SDA appointment is not one asset. It is two.

**A. The SDA freehold property.** Its value can depend on SDA in-use economics, the
underlying alternative-use property value, participant funding, occupancy quality,
location, design category, building type, fire sprinkler configuration, remaining SDA
pricing tenure, provider arrangements and buyer or investor mandates.

**B. The SDA provider business or provider rights.** Distinct from the freehold asset.
Its economics and risks can involve provider registration, participant relationships,
service and management agreements, claiming and administration, tenancy and provider
transition, contractual rights and obligations, current sustainable cash flow, work in
progress / participant pipeline, brand / reputation value, and geographical reach. This
report does not attempt a full provider-business valuation — the point is narrower: an
appointee needs to know these are not interchangeable assets before assuming either
one's position for the other.

Because the class is nascent, SDA in-use value and alternative-use value can diverge
significantly, in either direction. Sometimes that gap reflects a fundamental
impairment. Sometimes it reflects a remediable chokehold. Specialist commercial
diagnosis is what tells the difference — this report explains why, not how to perform
that diagnosis yourself.

This report is a companion to *SDA Market Report 2026*, which provides commercial
insight into the SDA asset class's first decade. This report does not repeat that
material — it focuses on administration, distress, recovery and realisation for an
individual appointment.
