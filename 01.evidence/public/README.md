# SDA Administration Report — Public Evidence Notes v0.1

Purpose: local, portable abstractions of current primary public sources for Claude Code.

These notes are not substitutes for the underlying primary sources. They record what each source supports, the publication boundary, and the claims it can support. Where the primary file already exists in the repository, use that file as the citation source and use this note only as an interpretation aid.

Rules:
- Prefer the primary source itself for final citations.
- Do not strengthen claims beyond the wording supported by the source.
- Do not infer SDA-specific insolvency from ASIC aggregate statistics.
- Do not infer that 2026 plan-reassessment reforms caused or stopped SDA approvals; the public sources establish the change in reassessment conditions, not that causal claim.
- Do not convert maximum SDA pricing into guaranteed income.
