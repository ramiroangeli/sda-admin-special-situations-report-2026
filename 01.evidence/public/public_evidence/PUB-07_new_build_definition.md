# PUB-07 — SDA "New Build" classification date (1 April 2016)

## Source status
Live NDIS primary-document fetch blocked (ndis.gov.au returns HTTP 403 to automated
tools, consistent with PUB-02/Round 1.1 findings). Verified via web search returning
consistent, convergent third-party technical summaries (SDA design/pricing
consultancies) of the NDIS SDA Price Guide / Design Standard definition, cross-checked
across two independent searches.

## What is supported
A dwelling is classified **New Build** where its first certificate of occupancy (or
equivalent) was issued on or after **1 April 2016** (new construction), or where a
refurbished existing dwelling was issued a post-1-April-2016 certificate of occupancy
and meets the minimum requirements for a design category other than Basic, at or above
the SDA Price Guide's minimum refurbishment cost threshold.

## Guardrail — what this does NOT support
This is a **classification/design-standard threshold**, not a statement that SDA
itself, or the scheme, began on 1 April 2016 (SDA participant funding under the NDIS
predates this date). Do not conflate "New Build classification began 1 April 2016"
with "SDA began 1 April 2016." Page 2 copy is worded to avoid this conflation.

This note does **not** independently re-verify the separate, already-flagged, still-open
Round 1.1 question of the exact New Build → Existing Stock pricing-tenure transition
period (see `evidence_gap_resolution_round1.1.md` §3 and page 12's own evidence note,
unchanged this round) — multiple independent secondary sources this round again
described a 20-year, certificate-of-occupancy-based transition, which is corroborating
but still not a primary document this project could retrieve and freeze. That flag
remains `PRIMARY SOURCE CONFIRMATION REQUIRED` and is out of scope for this round's
page 2 edit.
