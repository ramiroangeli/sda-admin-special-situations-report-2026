# INT-08 - Transaction Readiness / Vendor DD Patterns

## Scope
Derived from SDAHC vendor DD reports, information memoranda, sale schedules and settled/advanced transaction workflows.

## Repeated buyer-readiness issues
- participant and funding evidence;
- actual income versus theoretical income;
- vacancy history;
- provider arrangements and termination/transfer position;
- re-enrolment/certification risk;
- historical valuations and current assumptions;
- property condition, maintenance and CAPEX;
- title, tenancy and legal documents;
- clear sale/settlement transition plan.

## Evidence from transaction workflow
An advanced sale process reviewed by SDAHC required provider agreement, provider-transition notice, new participant/tenancy documentation and enrolment sequencing to be coordinated around settlement. This demonstrates that operational transition can be a transaction critical path.

## Report implication
A clean IM is not the same as a transaction-ready SDA asset. Information readiness and resolved transition mechanics reduce uncertainty that would otherwise appear in buyer DD or pricing.
