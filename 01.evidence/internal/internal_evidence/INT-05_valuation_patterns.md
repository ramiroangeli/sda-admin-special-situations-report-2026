# INT-05 - Professional Valuation and Value-Lens Patterns

## Scope
Synthesis from multiple professional SDA valuations and SDAHC DD/valuation analysis. Names, locations and values removed.

## Strong recurring evidence

### In-use SDA value and alternative-use value can be materially different
Professional valuations reviewed by SDAHC have separately assessed an SDA in-use/cashflow value and an alternative residential/property value.

### In-use value is conditional
Valuation assumptions reviewed include combinations of:
- SDA design/enrolment status;
- participant number and funding mix;
- occupancy/vacancy;
- provider arrangement;
- operating expenses;
- sinking fund / CAPEX;
- lease-up allowance;
- discount/capitalisation assumptions;
- continuing eligibility for SDA funding.

### Built capacity can differ from adopted economic occupancy
A regional valuation reviewed by SDAHC adopted a long-term participant level below the physical built capacity because the valuer considered location, participant pipeline and realistic operating conditions.

### Certification/enrolment assumptions matter
Internal DD has identified examples where the participant capacity or certification position used in an historical valuation required re-checking against the actual asset documentation.

## Report implication
A headline valuation should be treated as the output of assumptions that may change by the time an administrator, receiver or lender is making a recovery decision.

## Three value lenses
1. Stabilised SDA value.
2. Current special-situation SDA value.
3. Underlying property / alternative-use value.
