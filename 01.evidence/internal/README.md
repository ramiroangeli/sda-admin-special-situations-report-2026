# SDA Administration Report - Sanitised Internal Evidence Pack v0.1

Purpose: provide Claude Code with evidence-derived working notes without direct access to Notion or SharePoint and without copying confidential source documents into the report repository.

Rules:
- This pack is not a substitute for the original source documents.
- It contains anonymised patterns and conclusions only.
- Do not infer client, lender, provider, buyer or property identities.
- Do not add transaction-specific figures, names or addresses.
- Public copy must still obey the claim status and confidentiality rules in `../../00.project/confidentiality_rules.md`.
- When a note says STEVE VALIDATION REQUIRED, treat the point as a working framework rather than a settled fact.

Evidence IDs in this pack map to the internal source families already created in the working pack. The raw source mapping remains outside Claude Code.
